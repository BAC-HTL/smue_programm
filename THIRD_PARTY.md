# Bestandteile von Dritten

Diese Bestandteile werden beim Bauen in `Smue-Programm.html` und die Schüler-Datei eingebettet.

| Bestandteil | Version | Lizenz | Zweck |
| --- | --- | --- | --- |
| [jsPDF](https://github.com/parallax/jsPDF) | 2.5.2 | MIT | PDF-Auswertung |
| [Atkinson Hyperlegible](https://fontsource.org/fonts/atkinson-hyperlegible) | 5.3.0 (Fontsource) | SIL Open Font License 1.1 | Schrift der Oberfläche |
| [Barlow Condensed](https://fontsource.org/fonts/barlow-condensed) | 5.3.0 (Fontsource) | SIL Open Font License 1.1 | Punktezahlen |
| [JetBrains Mono](https://fontsource.org/fonts/jetbrains-mono) | 5.3.0 (Fontsource) | SIL Open Font License 1.1 | Timer und Ziffern |
| [Caveat](https://fontsource.org/fonts/caveat) | 5.3.0 (Fontsource) | SIL Open Font License 1.1 | Schriftzug im Lehrer-Programm |
| [DejaVu Sans Condensed](https://dejavu-fonts.github.io/) | Teilmenge in `fonts/` | DejaVu Fonts License (frei, auf Bitstream Vera basierend) | Schrift im PDF |

Zum Testen wird [Playwright](https://playwright.dev/) (Apache 2.0) verwendet. Es ist nicht im Programm enthalten.
